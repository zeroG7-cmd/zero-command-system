World Settings

Shadow's real tuned values, pulled straight from the actual Gazebo/ArduPilot SDF and param files on your Ubuntu machine — read-only here on purpose. Want to tweak values and watch it react live instead? That's what the Test Bench panel is for.

Gravity9.82 m/s² down
Standard Earth gravity, the exact value this sandbox's cannon.js physics uses (Gazebo uses its own close equivalent). Not editable — changing gravity isn't a thing your real drone will ever face.
Frame250mm X-quad
Diagonal motor-to-motor distance on Shadow's real airframe.
Props5″ (0.0635m radius)
Real propeller size, which is why Shadow needed its own LiftDrag numbers instead of iris's.
Drone's real mass0.85 kg
Shadow's actual measured weight, from the real SDF model Gazebo loads on your machine.
LiftDrag area0.0014
A Gazebo aerodynamics setting: how much lift one rotor blade generates per unit of simulated airspeed. Bigger means more thrust at the same spin speed. This is the number from tonight's saga — 0.0008 was too weak to get off the ground, iris's 0.002 was probably oversized for Shadow's smaller props, 0.0014 is what actually flies clean.
LiftDrag cp±0.059
Center of pressure offset for that same aerodynamic model, in meters. It's paired with area above inside Gazebo's LiftDrag plugin math, not something tuned by itself.
p_gain0.02 (x4 channels)
How hard each rotor's spin speed chases ArduPilot's commanded speed. iris's value of 0.20 was too aggressive for Shadow's lighter frame and failed PreArm; 0.02 is what let it arm and fly cleanly.
Last real ceiling5 m
Highest altitude Shadow has actually reached in a confirmed real sim flight tonight.
AutopilotArduCopter V4.8.0-dev
The real flight-controller firmware version running the control loops in SITL, same code that would fly the real Navio2.

Training Lab

Real episodes run so far: 0. Shadow itself has only ever been hand-flown through MAVProxy, never trained by a policy, but the button below runs a genuine small learning loop, live, right here.

Each click runs 25 real episodes: a tiny learned controller (2 weights + a bias, no more) proposes a thrust response to a physics-simulated drone falling under real gravity in cannon.js. If a randomly-tweaked version does better than the best one so far, it's kept; if not, it's thrown away. That is a real evolution-strategy search, the simplest honest form of "fail, measure, improve" - not scripted, and the chart above is drawn from its actual results, not a mockup.
